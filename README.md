# CloudGuard IAM

## Project Overview
CloudGuard IAM is an AWS Identity and Access Management (IAM) project focused on implementing secure user authentication and authorization using IAM users, groups, policies, and roles.

## AWS Services Used
- AWS IAM

## Features
- Created IAM users and groups
- Implemented custom IAM policies
- Configured IAM roles
- Applied least-privilege access principles
- Tested role-based access control

## Architecture

Admin User
    |
IAM Groups
    |
IAM Policies
    |
IAM Users & Roles

## Steps Performed
1. Created IAM users.
2. Created IAM groups.
3. Attached managed and custom policies.
4. Configured IAM roles.
5. Validated user permissions.

## Outcome
Implemented secure access management and role-based authorization in AWS.
